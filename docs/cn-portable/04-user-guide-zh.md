# Tokrate-CN 便携版 · 中文使用说明

适用版本：Tokrate-CN Portable 0.1.31（Windows x64，免安装）
文档更新：2026-11-16

---

## 1. 这是什么

Tokrate-CN 是一个托盘小工具：它读取你电脑上 Codex 等 AI 编程工具**本地已有的会话日志**，算出模型回答的吞吐速度（tok/s），显示在托盘和仪表盘里。

便携版的特点：

- **解压即用**：没有安装程序，不写注册表，不需要管理员权限；
- **数据随身带**：所有设置、历史、缓存都在程序旁边的 `data` 文件夹里；
- **不碰你的代码和凭证**：只读日志，不修改 Codex 的登录凭证或配置；
- **可共存**：可以和官方 Tokrate 同时安装，互不覆盖数据。

---

## 2. 第一次使用

1. 把 `Tokrate-CN-Portable-win-x64.zip` 解压到**非系统盘的可写目录**，例如：
   `D:\Tools\Tokrate-CN\`
   解压后应看到 `Tokrate-CN.exe`、`README-CN.txt`、`data\` 三项。
2. 双击 `Tokrate-CN.exe`。
3. 首次启动会询问是否允许向社区共享测量数据。**选“仅本地使用”即可**，仪表盘功能不受影响。
4. 托盘出现图标后，左键单击打开仪表盘；右键是菜单。

> 不要直接在压缩包里双击运行，也不要放在 `C:\Program Files` 这类需要管理员权限的目录。
> 这两件事都会让 `data\` 无法写入，程序会直接提示错误并退出（这是有意设计，避免偷偷写 C 盘）。

### 系统要求

- Windows 10/11 x64；
- Microsoft Edge **WebView2 Runtime**：Windows 11 自带；Windows 10 通常随 Edge 安装。缺失时程序无法显示界面，请到微软官网安装 “WebView2 Runtime（Evergreen）”。

---

## 3. 数据放在哪里

所有可写文件都在 `Tokrate-CN.exe` 同级的 `data\` 下：

| 路径 | 内容 | 说明 |
| --- | --- | --- |
| `data\settings.json` | 开关、数据源目录、语言等设置 | 纯 JSON，可直接备份 |
| `data\history.json` | 本地历史记录与读取检查点 | 保留最近 7 天、最多 5 万条 |
| `data\update-preferences.json` | 更新检查偏好 | 便携版不自动更新，通常为空设置 |
| `data\webview\` | WebView2 的缓存、localStorage | 语言选择存在这里 |
| `data\cache\` | 临时文件 | 可安全删除（程序退出后） |
| `data\logs\` | 预留的日志目录 | 当前版本不主动写日志文件，可能为空 |

**备份 / 换电脑**：退出程序后，把整个文件夹（含 `data\`）复制走即可。
**清理历史**：退出程序，删除 `data\history.json`，下次启动会重新统计（不会重新上传旧数据）。

## 4. 语言

- 本便携版**默认简体中文**。
- 打开“设置 → 语言”，可在“简体中文 / English”之间切换，立即生效，无需重启。
- 语言选择保存在 `data\webview\` 里，随文件夹一起移动，下次启动沿用。
- 当前开发版本的界面汉化尚未全部完成（共享同意页、效率说明、更新页等仍有英文）；正式发布前会清零。
  界面中出现的英文属于未完成项，不是你的配置问题。

## 5. 识别 Codex 日志目录

程序默认按以下顺序找 Codex 会话：

1. 环境变量 `CODEX_HOME`（如果设置了）下的 `sessions\`；
2. 否则 `%USERPROFILE%\.codex\sessions\`（通常是 `C:\Users\你的用户名\.codex\sessions`）。

判断是否识别成功：打开仪表盘 → 设置 → 数据源，Codex 一行显示“已找到”并给出路径与文件数。
如果没有：

- 确认路径下存在 `*.jsonl` 会话文件（先正常使用一次 Codex）；
- 点“选择文件夹”，手动指向 `sessions` 目录；
- 点“恢复默认”可回到自动识别的路径。

程序**只读**这些文件，不写入、不改名、不删除，也不会读取 Codex 的 `auth.json` 等登录凭证。

### 其他数据源

同样支持 Claude Code、Grok Build、Antigravity、OpenCode、Kimi Code。在“设置 → 数据源”里可以逐项选择目录；
检测不到的项显示为“未找到”，不影响其他数据源。

---

## 6. 监测开关

- 设置 → 通用 → **监测编程工具会话**：关闭后停止读取日志，托盘显示“监测已暂停”，历史保留。
- 设置 → 共享 → **与社区共享**：默认关闭。开启后才会向 `tokrate.dev` 上传**数值型**测量结果（模型名、token 数、耗时等），不上传提示词、回答正文、代码或路径。
- 关闭共享后，程序会取消上传任务并停止请求社区接口；本地仪表盘继续工作。

---

## 7. 与官方 Tokrate 共存

- 便携版使用独立的产品标识与独立的 `data\` 目录，**不会覆盖官方版的数据**，两者可以同时运行。
- 托盘图标可能相同，建议把其中一个固定到不同的托盘位置以便区分。
- 注意：如果你在便携版里开启过社区共享，签名身份保存在 **Windows 凭据管理器**（条目名与官方版相同，均为 `dev.tokrate.desktop` 相关）。两版会复用同一个匿名身份；这不会上传你的账号信息，但两版的贡献记录无法区分。

---

## 8. 升级

便携版**不做自动更新**（已从构建配置中移除更新器与更新源），不会自行联网下载新版本。

升级步骤：

1. 退出 Tokrate-CN（托盘右键 → 退出）；
2. 下载新的 ZIP，解压；
3. 只用新的 `Tokrate-CN.exe` 覆盖旧文件，**保留 `data\` 文件夹**；
4. 重新启动。

---

## 9. 卸载

1. 托盘右键 → 退出；
2. 删除整个 `Tokrate-CN` 文件夹。

没有安装程序，因此没有“卸载残留”。但有两种例外需要手动处理：

- **Windows 凭据管理器**：如果你开启过社区共享，删除文件夹不会删除系统凭据库里的匿名签名密钥。
  打开“控制面板 → 凭据管理器 → Windows 凭据”，找到 `dev.tokrate.desktop` 相关条目并删除。
- **你自己复制到别处的 `data\` 备份**：需要自行删除。

## 10. 常见问题

**双击没反应 / 一闪而过**
多为 `data\` 无法创建：检查是否放在只读目录、压缩包内、`Program Files`，或磁盘已满。程序会弹出中文错误框说明具体路径。

**提示缺少 WebView2**
安装微软 “WebView2 Runtime（Evergreen）”；Windows 11 一般不需要。

**仪表盘一直没有数字**
1. 确认“监测”开关是开的；
2. 设置 → 数据源 里对应工具是否“已找到”；
3. Codex 需要有已完成的回答（正在生成的回答按设计不计入吞吐）；
4. 选择“全部模型”并等待一次回答结束。

**托盘图标不见了**
Windows 可能把它折叠进“隐藏的图标”；在任务栏设置里把它设为常显。程序仍在运行。

**会不会上传我的提示词或代码？**
不会。上传逻辑使用固定字段白名单，只有模型名、token 数、耗时等数值；提示词、回答、代码、文件路径、会话 ID 都不在字段里。可在“设置 → 共享 → 查看具体发送内容”看到真实请求样例。

**会不会影响 Cockpit / Codex 的速度？**
Tokrate 只读日志文件，不写、不加独占锁。是否有可感知影响需要在你的机器上与 Cockpit 同跑观察，步骤见 `docs/cn-portable/06-local-verification-steps.md`。

**为什么删除文件夹后凭据管理器还有条目？**
见第 9 节：这是 Windows 凭据库的独立存储，不是安装残留，可手动删除。

## 11. 反馈问题时请附上

- Windows 版本（`winver`）；
- 是否安装 WebView2；
- `data\settings.json`（如有，注意其中只有目录路径与开关，不含对话内容）；
- 出错时的中文提示原文或截图；
- 是否同时运行了 Cockpit / 官方 Tokrate。
