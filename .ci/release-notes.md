Tokrate-CN 便携版 · Windows x64

下载 `Tokrate-CN-Portable-win-x64.zip`，解压到任意可写目录即可使用，无需安装。

- 解压后直接运行 `Tokrate-CN.exe`。
- 所有数据（设置、历史、WebView2 缓存）都保存在同目录的 `data/` 里，不写入 C 盘用户目录；删除文件夹即等于卸载。
- 需要系统已安装 WebView2 Runtime（Windows 11 自带；Windows 10 一般随 Edge 已安装）。
- 便携版不做自动更新：需要升级时重新下载本页的 ZIP 并覆盖 `Tokrate-CN.exe`，保留 `data/`。
- 校验文件：`Tokrate-CN-Portable-win-x64.zip.sha256`。
